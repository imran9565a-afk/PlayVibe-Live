# PLAYVIBE LIVE

Android starter prototype for a social live-video and friends gaming app.

Includes home dashboard, sample live-room cards, friends, game placeholders, demo coins and gifts, local display-name edit, and GitHub Actions APK build.

IMPORTANT: Real live video/audio, accounts, chat, friend presence, multiplayer, cloud profile photos, monetization and withdrawals are NOT connected. They need secure backend services, authentication, moderation, privacy controls and payment/legal review. Demo coins have no cash value.

GitHub Actions builds a debug APK on push to main/master or manual dispatch. Download artifact PlayVibe-Live-debug-apk after a successful run.
